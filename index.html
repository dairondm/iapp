Instrumento

Se autocompletan según el instrumento (ej. 100,000 divisa base para forex, 100 onzas para oro, 1 contrato para índices/cripto). Solo edítalos si tu bróker usa un tamaño distinto — el cálculo normal solo necesita el lotaje.
Importante: para oro y plata no existe un estándar único — algunos brokers definen 1 pip = $0.01, otros = $0.10 (10x de diferencia en tu resultado). Verifícalo en tu plataforma real (en MT4/MT5: clic derecho sobre XAUUSD → Especificación → revisa "Tick size" o "valor de un pip") y ajusta el campo "Tamaño del pip" de arriba si no coincide con el valor por defecto (0.01).
